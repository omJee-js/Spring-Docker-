# Java Spring Boot Microservices Project

## Overview
This project demonstrates a **Microservices-based architecture** built using **Spring Boot**. The system is divided into independent services that communicate with each other through REST APIs. The goal of this project is to understand how microservices interact, scale, and maintain modularity in modern backend systems.

The project follows key principles of **distributed systems**, **service isolation**, and **scalable backend design**.

---

## Features

- Microservices architecture using Spring Boot
- Independent services with separate responsibilities
- RESTful API communication between services
- Scalable and modular backend design
- Easy to extend with additional services
- Clean project structure following best practices
